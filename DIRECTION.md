# FluffyJaws Dev Studio — Direction Lock

## Thesis

FluffyJaws Dev Studio gives software work a room: a persistent, inspectable workcell whose active surfaces stay coordinated while Git remains the durable truth plane beneath them.

## Visual system

- **Industry pattern:** operating-system editorial / exploded axonometric systems atlas
- **House name:** Attached Workcell
- **Depth:** house system, EDS-native
- **Room:** both — jury-level object conviction with critic-room readability and native scroll

## One object

The site is one exploded **Attached Workcell**:

- Space is the enclosing frame.
- Conversations and panes are active bays.
- Browser is the outward-facing viewport.
- Vault is the locked inner compartment.
- Artifacts have a registered tray.
- Background commands leave a visible execution bay.
- Managed worktree attachment is a physical tether to a separate Git truth plane.

A stranger should be able to say, “that is a workspace whose surfaces stay attached to the work,” before reading the wordmark.

## One law

Every surface is visibly attached to—or explicitly separate from—durable project truth.

The law is structural, not decorative. It governs the hero, the state model, the surface catalog, and the workflow rail. Motion may only clarify an attachment or state change; it may not create ambient developer noise.

## Field and material

- **Field:** signal chartreuse and graphite
- **Neutral:** warm drafting stock
- **Material:** attachment blue, used only for selected surfaces, tethers, and proof/focus states
- **Type:** direct system grotesk plus system monospace; no Roboto Condensed sibling rhyme
- **Geometry:** hard edges, drafting lines, physical offsets, no generic rounded SaaS cards

## Forbidden sibling

`somarc/fluffyjaws-eds` is the forbidden sibling.

Do not reuse its:

- teal / rust / gold / mint palette;
- Roboto Condensed + Roboto pairing;
- looping full-viewport video splash;
- cream graph-paper field;
- bordered card grid and circular-number system map;
- after-hero sequence of parallel feature cards and generic CTA bands.

The older site is evidence of an earlier product framing, not a visual template.

## Silence

Refuse:

- a second hero;
- WebGL as LCP;
- scroll-jacking or a loader overture;
- fake telemetry, terminal rain, fictional metrics, or decorative logs;
- one rounded card per feature;
- screenshots containing private workspace names or credentials;
- a third accent color;
- any claim that Studio app state is Git-versioned;
- any duplication of project doctrine into high-priority space context.

## Content spine

The page progresses from basic use to expert state ownership:

1. Give the work a room.
2. Learn the visible workspace surfaces.
3. Compose surfaces into repeatable workflows.
4. Separate Git-backed project truth from app-managed Studio state.
5. Promote durable conclusions to the correct owner.
6. Keep secrets in Vault and user-facing exports in Artifacts.

## Evidence contract

Claims must map to observed Studio capabilities:

- spaces and repository roots;
- conversations and transcripts;
- split agent and terminal panes;
- a per-space browser with persistent profile and tabs;
- OS-encrypted Vault credentials;
- registered user-facing artifacts;
- Studio-managed background commands;
- branch-backed managed worktree attachment;
- focused child-agent research returning to the parent conversation.

Do not imply that Studio commits automatically, that transcripts enter Git, that draft paths are private, or that app persistence is a source-control contract.
